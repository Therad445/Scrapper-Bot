# LinkTracker Bot Service

LinkTracker – приложение для отслеживания обновлений контента через Telegram-бота.

## Описание

Сервис Bot отвечает за:
- **Обработку сообщений пользователей в Telegram.**  
Поддерживаемые команды:
- `/start` — регистрация пользователя.
- `/help` — вывод списка команд.
- `/track` — начать отслеживание ссылки (с диалогом для ввода URL, тэгов, фильтров).
- `/untrack` — прекратить отслеживание ссылки.
- `/list` — показать список подписок.

- **Управление подписками через REST API.**  
  Реализованы следующие эндпоинты:
  - `POST /tg-chat/{id}` — регистрация чата.
  - `DELETE /tg-chat/{id}` — удаление чата.
  - `GET /links` — получение списка отслеживаемых ссылок (требует заголовок `Tg-Chat-Id`).
  - `POST /links` — добавление ссылки (требует заголовок `Tg-Chat-Id`).
  - `DELETE /links` — удаление ссылки (требует заголовок `Tg-Chat-Id`).
  - `POST /updates` — получение уведомлений от Scrapper-сервиса (объект LinkUpdate согласно OpenAPI-контракту).
- **Обработка уведомлений от Scrapper-сервиса.**  
  Полученные уведомления логируются, а в будущем – отправляются пользователям через Telegram API.
- **Реализация машины состояний.**  
  Для команды `/track` реализована логика диалога, где пользователь поэтапно вводит URL, тэги и фильтры.
- **Шаблон «Репозиторий».**  
  Данные о чатах и ссылках хранятся через in‑memory репозитории, что позволит позже легко перейти на PostgreSQL.
- **Автоматическая регистрация команд через метод `setMyCommands`**  
  (бонусное требование).

## Требования

- Java 11 или выше
- Maven

## Настройка

1. Отредактируйте файл `src/main/resources/application.properties`:
   - Укажите `telegram.bot.token` (токен вашего Telegram-бота).
   - Укажите `telegram.bot.username` (имя вашего бота).

## Запуск

Из корневой папки сервиса `bot` выполните:

```bash
mvn spring-boot:run
```
