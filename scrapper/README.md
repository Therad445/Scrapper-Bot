# LinkTracker Scrapper Service

Scrapper-сервис отвечает за мониторинг обновлений по отслеживаемым ссылкам и уведомление Bot-сервиса.

## Описание
Сервис Scrapper выполняет следующие функции:
- **Мониторинг ссылок:**  
  С периодическим запуском (через аннотацию `@Scheduled`) проверяет наличие обновлений для ссылок, хранящихся в репозитории.

- **Хранение отслеживаемых ссылок:**  
  Используется слой репозитория (интерфейс `TrackedLinkRepository` с in‑memory реализацией).  
  Позволяет легко перейти к использованию базы данных в будущем.

- **Отправка уведомлений:**  
  При обнаружении изменений формируется объект обновления (`LinkUpdate`), который соответствует схеме из bot‑api.yaml.  
  Уведомление отправляется через HTTP-клиент (NotificationClient) на Bot-сервис по эндпоинту `/updates`.

- **Планировщик задач:**  
  Периодически (например, каждую минуту) проверяет все отслеживаемые ссылки и отправляет уведомления о найденных обновлениях.

## Требования
- Java 11 или выше
- Maven

## Настройка
1. Отредактируйте файл `src/main/resources/application.properties`:
    - Укажите `bot.service.url` — URL Bot-сервиса (например, `http://localhost:8080`).
    - Проверьте порт сервера (по умолчанию `8081`).
